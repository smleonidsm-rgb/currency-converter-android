# Курс Динара — конвертер RSD → RUB / EUR / USD

Нативное Android-приложение (Kotlin + Jetpack Compose) без рекламы. Вводишь сумму
в сербских динарах — сразу видишь эквивалент в рублях, евро и долларах. Курс
подтягивается из интернета и обновляется автоматически раз в час (плюс кнопка
ручного обновления), последний известный курс кэшируется на телефоне и
показывается даже офлайн.

## 1. Установи Android Studio

1. Скачай Android Studio с официального сайта: https://developer.android.com/studio
2. Запусти установщик, оставь настройки по умолчанию (он сам поставит нужный
   JDK и Android SDK).
3. При первом запуске откроется мастер настройки — просто пройди его до конца
   (Standard install).

## 2. Получи бесплатный ключ для курсов валют

1. Зайди на https://www.exchangerate-api.com/ и нажми "Get Free Key".
2. Зарегистрируйся (email + пароль) — это нужно сделать самому, я этого не
   делаю за тебя.
3. После регистрации на дашборде появится API key — скопируй его.

## 3. Подключи ключ к проекту

1. Открой файл `local.properties` в корне проекта.
2. Замени строку

   ```
   EXCHANGE_API_KEY=YOUR_API_KEY_HERE
   ```

   на свой реальный ключ, например:

   ```
   EXCHANGE_API_KEY=abcd1234ef567890
   ```

Ключ не попадёт в git — `local.properties` в `.gitignore`.

## 4. Открой проект и запусти

1. В Android Studio: `File → Open` → выбери папку `RsdConverter`.
2. Дождись, пока внизу закончится "Gradle sync" (первый раз скачивает
   зависимости — может занять пару минут, нужен интернет).
3. Подключи телефон по USB с включённой отладкой по USB
   (Настройки → О телефоне → 7 раз тапнуть "Номер сборки" → Настройки для
   разработчиков → USB-отладка), либо создай виртуальное устройство
   (Device Manager → Create Device).
4. Нажми зелёную кнопку ▶ Run рядом с конфигурацией "app".

## Как пользоваться

- Тапни на флаг/код валюты в верхней карточке — откроется список из ~60 валют
  мира с поиском по коду или названию (например "тенге" или "AED"). Выбранная
  валюта становится источником пересчёта.
- Ниже — карточки с результатом для отслеживаемых валют. Кнопкой
  "+ Добавить валюту" можно добавить в этот список любую валюту, крестиком
  на карточке — убрать. Список сохраняется между запусками.
- Например: выбери источником EUR — увидишь RSD/RUB/USD; добавь GBP — он
  тоже появится в списке и будет пересчитываться из EUR.
- Под полем ввода — кнопки быстрых сумм 50 / 100 / 500 / 1000.
- Под каждой карточкой мелким текстом обратный курс ("1 EUR = 117,4000 RSD"),
  а справа стрелка ↑/↓ с процентом изменения относительно предыдущего дня
  (появится, когда накопятся данные хотя бы за два разных дня).
- Иконка палитры в шапке переключает оформление между фирменным
  тёмно-синим/золотым стилем и цветами из обоев (Material You, Android 12+).

## Как это устроено

- `data/ExchangeRateApi.kt` — Retrofit-запрос к exchangerate-api.com
  (`GET /v6/{key}/latest/{base}`), бесплатный план обновляет курсы у них на
  сервере примерно раз в сутки.
- `data/RatesRepository.kt` — запрос (полный список валют из ответа API) +
  кэш в DataStore: курсы хранятся отдельной записью на каждую базовую валюту,
  поэтому при переключении RSD↔EUR данные показываются мгновенно из кэша,
  пока в фоне идёт обновление. Там же хранятся список отслеживаемых валют,
  выбор темы и курсы предыдущего дня для стрелки изменения.
- `ui/CurrencyCatalog.kt` — каталог валют (код, флаг, название по-русски)
  для поиска в диалоге выбора.
- `ui/CurrencyViewModel.kt` — держит состояние экрана. Автообновление раз в
  час работает только пока экран виден (`repeatOnLifecycle`), а свежий кэш
  (моложе часа) не перезапрашивается — так экономится месячный лимит запросов
  API. Ручная кнопка обновления запрашивает всегда.
- `data/RatesMath.kt` — чистые функции (санитайзер ввода, % за сутки,
  перекатывание вчерашнего курса) без зависимостей от Android, покрыты
  юнит-тестами в `app/src/test/`.
- `data/RatesError.kt` — типизированные ошибки: неверный ключ, исчерпанный
  лимит, нет сети и т.д. — каждая показывает свой баннер, а не общий «офлайн».
- `ui/MainScreen.kt` — сам экран: карточка ввода суммы, диалог выбора валюты
  с поиском, карточки результатов с возможностью добавлять/убирать валюты,
  баннер "нет соединения", когда офлайн.
- `ui/theme/` — фирменный тёмно-синий/золотой стиль с поддержкой светлой темы
  и опциональными динамическими цветами Material You.

## Сборка и тесты из терминала

В проекте настроен Gradle wrapper, так что Android Studio не обязателен для
сборки (нужен только установленный JDK 17+; проще всего указать на тот, что
идёт с Android Studio, через `JAVA_HOME`):

```bash
./gradlew testDebugUnitTest   # прогнать юнит-тесты
./gradlew assembleRelease     # собрать релизный APK (R8 + ProGuard)
```

Юнит-тесты покрывают денежную математику и разбор ввода — то, где тихая
ошибка опаснее всего. Релизная сборка проверена: R8-минификация проходит,
правила ProGuard сохраняют сериализаторы Retrofit/kotlinx.serialization.

## Публикация в Google Play

Приложение уже настроено на подписанную релизную сборку — осталось создать
ключ и заполнить страницу в Play Console.

### Создай ключ подписи

Ключ создаётся один раз и хранится вечно: потеряешь — не сможешь выпускать
обновления уже опубликованного приложения. Сделай резервную копию.

В Android Studio: `Build → Generate Signed App Bundle / APK → Android App Bundle
→ Create new...`, заполни поля и сохрани файл `release-key.jks` в корень
проекта. Пароли запомни/сохрани в менеджере паролей.

### Подключи ключ к сборке

1. Скопируй `keystore.properties.example` в `keystore.properties`.
2. Впиши туда реальные пароли и alias, которые задал при создании ключа.

Файл в `.gitignore`, как и сам `.jks` — в репозиторий они не попадут.

### Собери App Bundle

`Build → Generate Signed App Bundle / APK → Android App Bundle` — на выходе
получится `app/release/app-release.aab`, именно его принимает Play Console.

### Что нужно сделать вручную в Play Console

Регистрацию аккаунта разработчика (единоразовый взнос $25), заполнение
карточки приложения и загрузку сборки нужно делать самому:

1. Аккаунт разработчика: https://play.google.com/console
2. Создать приложение, указать название, описание, категорию "Финансы".
3. Подготовить графику: иконка 512×512 PNG, шапка 1024×500, минимум 2
   скриншота телефона. Скриншоты проще всего снять с эмулятора
   (`Ctrl+S` в окне эмулятора) или с телефона.
4. Заполнить обязательные анкеты: политика конфиденциальности (нужен
   URL — приложение не собирает персональные данные, но декларация всё равно
   обязательна), возрастной рейтинг, Data Safety, целевая аудитория.
5. Загрузить `.aab` в тестовый трек, потом продвинуть в production.

Важно про API-ключ: он вшивается в сборку через `BuildConfig` и в
опубликованном APK его технически можно извлечь. Для личного приложения
и бесплатного тарифа это приемлемо, но при публикации на широкую аудиторию
лучше проксировать запросы через свой сервер или ограничить ключ в личном
кабинете exchangerate-api.

## Возможные доработки

- Добавить ещё валют в каталог — дописать в список `allCurrencies` в
  `ui/CurrencyCatalog.kt` (код ISO 4217, флаг-эмодзи, название).
- Поменять иконку приложения через Android Studio: `File → New → Image Asset`.
